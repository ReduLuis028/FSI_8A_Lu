**Challenge**
	
**Description**
	Morse code is well known. Can you decrypt this?Download the file [here](https://artifacts.picoctf.net/c/79/morse_chal.wav).
	Wrap your answer with picoCTF{}, put underscores in place of pauses, and use all lowercase.
	**Hints**
		1. Audacity is a really good program to analyze morse code audio.

**Solution**
	1. Download and upload the file.wav in the website [DATA BORDER](https://databorder.com/transfer/morse-sound-receiver/)
	2. Click on button `Play` and the date will be decrypted:
		![[Screenshot 2026-04-26 180453.png]]
	3. Then we'll have the message decrypted:
		`WH47 H47H 90D W20U9H7`.
	4. Wrap the flag in the Pico format: `picoCTF{...}`.
	5. Flag: `picoCTF{WH47_H47H_90D_W20U9H7}`.
