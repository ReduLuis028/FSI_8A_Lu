**Challenge**
	
**Description**
	What does asm2(0x8,0x2e) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/e52eb78a50fe37d5d90fa3200de17edb7b6e51a3e01c583cec0ed94d9e9bc306/test.S)
	**Hints**
		1. assembly conditions.

**Solution**
	1. Open and analyze the `test.S` assembly file.
	2. Identify the function call:
		<script>
			asm2(0x8,0x2e)
		</script>
	3. The function stores the arguments in local variables:
		<script>
			[ebp-0x8] = 0x8
			[ebp-0x4] = 0x2e
		</script>
	4. The loop condition is:
		<script>
			cmp DWORD PTR [ebp-0x8],0xe6da
			jle 0x11c5
		</script>
	5. Inside the loop:
		<script>
			add DWORD PTR [ebp-0x4],0x1
			add DWORD PTR [ebp-0x8],0xed
		</script>
	    - The first variable increases by `1`
	    - The second variable increases by `0xed` each iteration
	6. Calculate the number of iterations:
	    <script>
		    0x8 + (0xed × 249) = 0xe68d
	    </script>
	    - Still less than `0xe6da`, so the loop continues.
	    - Next iteration:
	    <script>
		    0x8 + (0xed × 250) = 0xe77a
	    </script>
	    - Now it is greater than `0xe6da`, so the loop stops.
	7. The first variable started at `0x2e` and increased once per iteration:
		<script>
			0x2e + 0xfa = 0x128
		</script>
	8. Flag:
		<script>
			0x128
		</script>
