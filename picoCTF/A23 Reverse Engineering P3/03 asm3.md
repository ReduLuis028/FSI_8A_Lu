**Challenge**
	
**Description**
	What does asm3(0xc2cb1015,0xb886b227,0xee8ecb38) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/dc2affc42a0374a7e3d3b2f4936eb083fa4ade553b99c00b2002eb3bd024664c/test.S)
	**Hints**
		1. more(?) registers.

**Solution**
	1. Open and analyze the `test.S` assembly file.
	2. Identify the function call:
		<script>
			asm3(0xc2cb1015,0xb886b227,0xee8ecb38)
		</script>
	3. The function starts by clearing `eax`:
		<script>
			xor eax,eax
		</script>
	    - Now:
	    <script>
		    eax = 0x00000000
		    ax  = 0x0000
	    </script>
	4. Load one byte into `ah`:
		<script>
			mov ah,BYTE PTR [ebp+0x9]
		</script>
	    - First argument:
	    <script>
		    0xc2cb1015
	    </script>
	    - In little-endian memory:
	    <script>
		    15 10 cb c2
	    </script>
	    - `[ebp+0x9] = 0x10`
	    - Therefore:
	    <script>
		    ah = 0x10
		    ax = 0x1000
	    </script>
	5. Shift `ax` left by `0x10`:
		<script>
			shl ax,0x10
		</script>
	    - Since `ax` is a 16-bit register, shifting by 16 clears it:
	    <script>
		    ax = 0x0000
	    </script>
	6. Subtract one byte from `al`:
		<script>
			sub al,BYTE PTR [ebp+0xf]
		</script>
	    - Second argument:
	    <script>
		    0xb886b227
	    </script>
	    - In memory:
	    <script>
		    27 b2 86 b8
	    </script>
	    - `[ebp+0xf] = 0xb8`
	    - Calculation:
	    <script>
		    0x00 - 0xb8 = 0x48
	    </script>
	    - Now:
	    <script>
		    al = 0x48
		    ax = 0x0048
	    </script>
	7. Add one byte into `ah`:
		<script>
			add ah,BYTE PTR [ebp+0xe]
		</script>
	    - `[ebp+0xe] = 0x86`
	    - Calculation:
	    <script>
		    0x00 + 0x86 = 0x86
	    </script>
	    - Now:
	    <script>
		    ah = 0x86
		    ax = 0x8648
	    </script>
	8. XOR `ax` with a word from the third argument:
		<script>
			xor ax,WORD PTR [ebp+0x12]
		</script>
	    - Third argument:
	    <script>
		    0xee8ecb38
	    </script>
	    - In memory:
	    <script>
		    38 cb 8e ee
	    </script>
	    - `WORD PTR [ebp+0x12] = 0xee8e`
	    - Calculation:
	    <script>
		    0x8648 ^ 0xee8e = 0x68c6
	    </script>
	9. Flag:
		<script>
			0x68c6
		</script>
