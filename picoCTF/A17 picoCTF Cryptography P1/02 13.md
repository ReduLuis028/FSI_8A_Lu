**Description**
	Cryptography can be easy, do you know what ROT13 is?
	cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}
	**Hints**
		1. This can be solved online if you don't want to do it by hand!

**Solution**
	1. Rotate each letter 13 positions in the alphabet.
		- A ↔ N
		- B ↔ O
		- C ↔ P
	2. With this information, I did and run the following code:
		<script class = "Python">
			import codecs

			texto = "cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}"
			print(codecs.decode(texto, 'rot_13'))
		</script>
	3. Then we have the flag: `picoCTF{not_too_bad_of_a_problem}`.
