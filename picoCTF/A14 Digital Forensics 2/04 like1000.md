**Notes**
	1. Comandos y explicación
	    1.1. `wget https://challenge-files.picoctf.net/.../1000.tar`
	        `wget` → comando para descargar archivos desde la web.
	        `URL` → dirección del archivo que se quiere descargar.
	    1.2.`file 1000.tar`
	        `file` → detecta el tipo de archivo por su contenido.
	        `1000`.tar → archivo a inspeccionar. Resultado indica que es un archivo tar POSIX (GNU).
	    1.3.`tar -tf 1000.tar`
	        `tar` → herramienta para empaquetar/desempaquetar archivos en Linux.
	        `-t` → listar el contenido del tar.
	        `-f` → indica el nombre del archivo tar que se va a procesar.
	        `1000.tar` → archivo tar a listar.
	    1.4.`for i in {1000..1}; do tar -xf $i.tar && rm $i.tar; done`
	        `for i in {1000..1}` → bucle que recorre del 1000 al 1.
	        `tar -xf $i.tar` → extrae el contenido del archivo $i.tar.
	            `-x` → extraer.
	            `-f` → archivo a procesar.
	        `&& rm $i.tar` → si la extracción fue exitosa, elimina el archivo tar original.
	        `done` → indica el fin del bucle.
	        Esto sirve para desempaquetar todos los tars anidados de manera automática.
	    1.5.`open flag.png`
	        `open` → abre el archivo con la aplicación predeterminada del sistema (en Kali puede ser xdg-open).
	        `flag.png` → archivo de imagen que contiene la bandera.
